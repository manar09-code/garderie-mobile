# Captures d'écran

Enregistrez les captures de l'application Android dans ce dossier avec les noms
ci-dessous pour qu'elles apparaissent dans le README principal :

- `splash-screen.png` : écran de démarrage; relancez l'application et capturez
  l'écran avant la navigation automatique après 3 secondes.
- `home-page.png` : accueil avec la liste des activités.
- `drawer.png` : menu latéral ouvert depuis l'icône de menu.
- `interaction-message.png` : SnackBar affiché après avoir touché une activité
  ou le bouton « + ».

Dans Android Studio, ouvrez **Running Devices**, puis utilisez l'action **Take
Screenshot** de l'émulateur. Vous pouvez aussi utiliser l'icône de capture
d'écran dans la barre latérale de l'émulateur.
